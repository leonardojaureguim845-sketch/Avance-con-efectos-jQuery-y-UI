## Nota de organización
Esta carpeta documenta el hito dentro de la evolución del proyecto. El código ejecutable de la aplicación se mantiene centralizado en la raíz para evitar duplicar archivos y que las versiones semanales se desincronicen. El backend conserva su arquitectura modular porque sus controladores, servicios, middleware y validadores dependen unos de otros.
